# 동굴이야기 (Cave Story)

- 엔진: doukutsu-rs (Rust 재구현, 1.0.0)
- 라이선스: 원작은 Studio Pixel 프리웨어(2004).dou_1006.zip 공식 배포본 데이터 포함
- 설치 경로: `sdmc:/switch/doukutsu-rs/`
- 실행 파일: `doukutsu-rs.nro`
- 비고: 프리웨어 판본 기준으로 `Doukutsu.exe` 와 추출된 `data/` 를 NRO 와 같은 폴더에 두면 첫 실행에 인식합니다.
- 출처: https://github.com/doukutsu-rs/doukutsu-rs (switch NRO), https://studiopixel.jp (프리웨어 원본)
