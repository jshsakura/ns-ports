# 슈퍼 턱스 2 (SuperTux 2)

- 엔진: SuperTux Milestone 2 멀티콘솔 포트 (theheroGAC, GPLv3)
- 라이선스: 완전 무료 오픈소스 게임 (에셋 포함)
- 설치 경로: `sdmc:/switch/supertux2/`
- 실행 파일: `supertux2.nro`
- 비고: 게임 데이터 전체가 NRO 롬FS(~116MB)에 내장되어 별도 데이터 없이 실행됩니다. 세이브는 `sdmc:/switch/supertux2/userdata/` 에 저장됩니다.
- 출처: https://github.com/theheroGAC/SuperTux-Milestone-2-Multi-Console (릴리스 1.00)
