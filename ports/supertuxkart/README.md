## 필요한 파일과 명령어

| 넣을 위치 | 파일 |
| :--- | :--- |
| `ports/supertuxkart/in/supertuxkart.nro` | 스위치용 빌드 NRO |
| `ports/supertuxkart/in/data` | SuperTuxKart-1.5 데이터 (data/) |

- 원 프로젝트: https://github.com/supertuxkart/stk-code

```
python3 build.py check supertuxkart    # 빈 칸 확인
python3 build.py supertuxkart --zip
```

개인 테스트 기록. 한국어화 여부는 아직 확인하지 않았다.
